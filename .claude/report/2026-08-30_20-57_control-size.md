# 컨트롤 크기 데스크톱 우선 축소 — 변경 및 롤백 안내
> 작업일시: 2026-08-30 20:57

## 변경 이유
버튼·드롭다운이 크게 느껴진다는 지적을 계측으로 확인. 템플릿 전체 컨트롤 124개의
**높이 중앙값이 40px, 45%(56개)가 42px 이상**이었음.

데스크톱 데이터 위주 앱의 업계 기본값은 32~36px (Ant 32 / Primer 32 / Atlassian 32 /
Radix 32 / shadcn 36 / Bootstrap 38 / Material 40). 40px는 대부분 시스템에서 "large" 등급.

원인은 폰트가 아니라 세로 패딩. 본문은 `text-sm`(14px)로 표준인데 패딩이 10~12px였음.
44px는 Apple HIG 44pt / WCAG 2.5.5(AAA) 터치 타깃 수치로, 마우스 UI에 터치 규격이
적용된 상태였음. 마우스 환경의 실제 하한은 WCAG 2.2 AA(2.5.8)의 **24×24px**.

## 적용한 스케일

| 등급 | 용도 | 이전 | 이후 |
|---|---|---|---|
| icon | 정사각 아이콘 버튼 | 36px (`w-9 h-9`) | **32px** (`w-8 h-8`) |
| base | 필터·드롭다운·입력·날짜 | 38 / 42px | **34px** (`py-1.5` + border) |
| lg | 모달 푸터 주요 액션 | 44 / 46px | **42px** (`py-2.5` + border) |
| sm | 행 내 액션(보기/수정) | 30px | 유지 |

### 치환 규칙 (button / input / textarea / label[cursor-pointer] 요소에만 적용)
```
py-3    → py-2.5      26건
py-2.5  → py-1.5      38건
py-2    → py-1.5      20건
w-9 h-9 → w-8 h-8     13건
```
`py-*`는 카드·헤더 등 비컨트롤 요소에도 쓰이므로 태그 단위로 파싱해 컨트롤만 치환.

### 테두리 2px 정규화 (45건)
테두리 유무로 같은 등급 안에서 높이가 2px 어긋나는 문제가 있었음
(필터바: 드롭다운 34 vs 검색버튼 32 / 모달 푸터: 취소 42 vs 확인 40).
테두리가 없는 컨트롤에 `border border-transparent`를 추가해 높이를 통일.

## 제외한 범위
- `templates/login/`, `templates/user/`(회원가입), `templates/error/`
  — `border-hairline`, `rounded-md-1`, `shadow-btn-green`, flat 토큰(`bg`/`surface`/`text`)을
    쓰는 별도 디자인 언어의 인증/에러 페이지. 중앙 정렬 단일 폼이라 44~48px가 적절해 유지.
- 목록 행 높이(`px-6 py-4` = 52px) — 이번 요청 범위(버튼·드롭다운) 밖이라 미변경.
  Ant Design 기준 default 54 / middle 46 / small 38이므로 축소 여지는 있음.

## 롤백 방법

```bash
git apply -R .claude/report/2026-08-30_20-57_control-size-rollback.patch
npm run tw:build
```

패치는 변경 전 스냅샷과 현재 상태를 직접 비교해 생성했고 `git apply --check -R` 로
역적용 가능함을 검증함. 16개 파일 / 734줄.

**`git checkout --` 을 쓰지 말 것.** 대상 파일 중 `fixed-expense/index.html`,
`admin/logs/index.html`, `common/calendar.js` 등은 다른 세션의 미커밋 변경이 섞여 있어
HEAD로 되돌리면 그 작업까지 사라짐. 위 패치 역적용만이 이 변경만 정확히 취소함.

`output.css` 는 빌드 산출물이므로 역적용 후 재빌드로 갱신할 것.
