## 이슈 및 특이사항

**대시보드 전역 클릭 리스너 누수 (원인 분석만, 미수정)**
- 증상: `Uncaught TypeError: Cannot read properties of null (reading 'classList')` at `closePaymentDropdown (index.js:406)`
- 원인: `js/dashboard/index.js:128` 이 `document` 에 클릭 리스너를 등록하는데, htmx가 `#main-content` 만 교체하므로 대시보드 DOM이 사라져도 리스너는 `document` 에 잔존. 이후 아무 곳이나 클릭하면 `payment-dd-options` 조회가 null → TypeError
- 재현 조건: 한 번이라도 대시보드를 거친 세션에서만 발생 (달력 컴포넌트 자체와 무관)
- 부수 문제: 대시보드 재방문 시 스크립트가 재실행되어 `document` 리스너가 중복 누적
- 제시한 선택지: (a) 옵셔널 체이닝 방어 (b) `htmx:beforeSwap` 에서 해제 (c) `document` 대신 대시보드 루트 엘리먼트에 위임 — (c) 권장, **사용자 결정 대기 중**

**"매일 주기는 불필요" 안내 문구의 부정확성**
- 기존 라벨의 이 안내는 "과거 기준일 + 매일 주기"일 때만 참이었음
- `calculateNextDueDate()` 는 `anchorDt == null` 이면 즉시 null 반환하므로, 안내를 믿고 비워두면 다음 지출일이 `-` 로 표시됨
- 미래 기준일은 매일 주기에서도 결과에 영향을 줌
- → 사용자가 "기준일 필수화" 선택, 문구 제거 후 필수값으로 전환

**공통 드롭다운 fragment의 테마 하드코딩 (미수정)**
- `fragments/dropdown.html` 의 버튼이 `border-admin-border` / `hover:bg-admin-subtle` 로 admin 테마 고정
- cream 테마인 고정지출 모달에서 인접 컨트롤과 테두리·배경 색이 미세하게 불일치

## 미완료 / 후속 작업

**1. DB 반영 SQL 실행 필요 (사용자 실행 대기)**
```sql
SELECT COUNT(*) FROM TB_EX_FIXED_EXPENSE WHERE ANCHOR_DT IS NULL AND DEL_AT = 'N';
UPDATE TB_EX_FIXED_EXPENSE SET ANCHOR_DT = RGS_DT::DATE WHERE ANCHOR_DT IS NULL;  -- 백필 값 확인 필요
ALTER TABLE TB_EX_FIXED_EXPENSE ALTER COLUMN ANCHOR_DT SET NOT NULL;
COMMENT ON COLUMN TB_EX_FIXED_EXPENSE.ANCHOR_DT IS '기준일(시작일) (다음 지출 예정일 계산 기준. 매주/격주는 요일, 매월 계열은 일자, 매년은 월일을 이 날짜에서 추출)';
```
