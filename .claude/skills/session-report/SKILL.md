# 세션 작업 요약 보고서 생성

## 수행 절차

### 1단계: 변경 파일 목록 수집
`.claude/log/modified-files.log` 파일을 Read 도구로 읽어 수정/생성된 파일 목록을 파악합니다.

### 2단계: 대화 내용 분석
현재 대화 히스토리를 분석하여 다음을 파악합니다:
- 사용자가 요청한 작업 내용
- 완료된 작업과 미완료 작업
- 사용된 에이전트 목록
- 발생한 이슈와 해결 방법

### 3단계: 보고서 파일명 결정
- 오늘 날짜와 현재 시각 기준: `YYYY-MM-DD_HH-MM.md`
- `$ARGUMENTS`가 있으면 파일명에 추가: `YYYY-MM-DD_HH-MM_$ARGUMENTS.md`

### 4단계: 보고서 작성
아래 형식으로 보고서를 작성합니다:

```markdown
# 세션 작업 요약
> 생성일시: YYYY-MM-DD HH:MM

## 작업 개요
세션 주요 목표 한 줄 요약

## 완료된 작업

### 생성/수정된 파일
| 시각 | 작업 | 파일 경로 |
|------|------|-----------|
| HH:MM | Write/Edit | 경로 |

### 주요 변경 내용
- 변경 사항을 항목별로 정리

## 사용된 에이전트
- 에이전트명: 수행한 작업

## 이슈 및 특이사항
- 발생한 문제와 해결 방법

## 미완료 / 후속 작업
- 다음 세션에서 이어할 작업
```

### 5단계: 파일 저장
Write 도구로 `.claude/report/YYYY-MM-DD_HH-MM.md` 경로에 저장 후 저장된 경로를 사용자에게 알립니다.
