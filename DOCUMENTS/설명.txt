 가계부 프로젝트 — 개발 운영 설명
================================================================

----------------------------------------------------------------
 빌드 / 서버 반영 명령어
----------------------------------------------------------------

코드 변경 후 실행 중인 서버에 반영하려면 아래 명령어를 사용한다.
IntelliJ 터미널 또는 프로젝트 루트에서 실행.

▸ Java 파일 컴파일 (Controller, Service, Entity 등 변경 시)
  gradlew compileJava

▸ 템플릿/리소스 복사 (HTML, CSS, JS, application.properties 변경 시)
  gradlew processResources

▸ 둘 다 한 번에 (가장 자주 사용)
  gradlew classes && gradlew processResources

  → classes 는 내부적으로 compileJava 를 포함한다.
  → 실행 중인 서버에 DevTools 가 감지해 자동 재시작된다.

▸ 서버 전체 재시작이 필요한 경우 (의존성 추가, 설정 변경 등)
  IntelliJ 에서 직접 Run/Debug 재시작

----------------------------------------------------------------
 주의 사항
----------------------------------------------------------------

• Inner record/class 를 Controller 안에 선언하면 DevTools 재시작 시
  ClassNotFoundException 이 발생한다.
  → DTO record 는 반드시 별도 파일로 분리할 것.

• build/resources/main/templates/ 가 오래된 경우
  processResources 를 실행해 src → build 로 복사해줘야 한다.
