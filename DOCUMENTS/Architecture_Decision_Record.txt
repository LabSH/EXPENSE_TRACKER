[2026-06-22] 모달 backdrop 클릭 동작 기준
결정: 모달 종류에 따라 backdrop(바깥 영역) 클릭 동작을 구분
  - 단순 정보 확인 전용 모달 → backdrop 클릭 시 닫힘 허용
  - 등록·수정·삭제 등 기능이 있는 모달 → backdrop 클릭으로 닫히지 않음 (X 버튼·취소 버튼으로만 닫기)
이유: 폼 입력 중 실수로 바깥을 클릭했을 때 작성 내용이 날아가는 UX 손실 방지.
     삭제 확인 모달도 사용자가 의도한 액션이 있으므로 명시적 닫기를 요구함.
구현: backdrop 클릭 이벤트 리스너를 정보 확인 모달에만 등록할 것
